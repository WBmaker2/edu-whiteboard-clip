# 3D 분자 빌더

원자를 놓고 결합으로 이어 붙인 뒤, VSEPR 규칙으로 모양을 정리해 목표 분자를 완성하는 3D 교육 게임입니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/
```

## 조작

- **목표 분자** (물·메테인·암모니아·이산화탄소) — 맞출 분자를 고릅니다.
- **원자 팔레트** (H·C·N·O) — 고른 뒤 작업대를 누르면 원자가 놓입니다.
- **원자 클릭 → 다른 원자 클릭** — 두 원자 사이에 결합이 생깁니다. 같은 두 원자를 다시 누르면 결합 차수가 1 → 2 → 3 으로 올라갑니다.
- **결합 클릭** — 결합을 지웁니다.
- **예시 불러오기** — 목표 분자를 일직선으로 늘어놓은 상태로 불러옵니다.
- **자동 배치** — VSEPR 규칙으로 모양을 정리합니다.
- **검사** — 목표와 비교해 성공/실패와 해설을 보여 줍니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/stage.js` | 렌더러·조명·바닥 그리드·고정 스텝 루프·평면 피킹 |
| `src/elements.js` | 원자별 반지름·색상·원자가 전자 수 |
| `src/chemistry.js` | 목표 분자 정의, VSEPR 배치 계산, 판정 |
| `src/invariants.js` | 기하 불변식 (결합각 실측, 분자 축 ↔ 시선, 원자 겹침) |
| `src/chemistry.test.js` | 유닛 테스트 16개 (결합각·가독성·단위 계약·판정) |
| `src/main.js` | 원자·결합 관리, UI 배선, 불변식 배선, 상태 조회 API |

## 화학 규칙

- **비공유 전자쌍 수** = (원자가 전자 수 − 결합 차수 합) ÷ 2
  - 물의 산소: (6 − 2) ÷ 2 = 2쌍 → 전자 영역 4개
  - 암모니아의 질소: (5 − 3) ÷ 2 = 1쌍 → 전자 영역 4개
- **전자 영역** = 결합한 이웃 수 + 비공유 전자쌍 수
  - 4 → 정사면체 전자 기하, 3 → 평면 삼각형, 2 → 직선
- **결합각 압축**: 비공유 전자쌍이 있으면 결합을 서로 가까이 모읍니다.
  물 104.5° · 암모니아 107° · 메테인 109.5° · 이산화탄소 180°

배치는 정사면체 꼭짓점 4개에서 시작해, 결합이 들어갈 칸을 앞쪽으로 가져온 뒤 **결합 군 중심 쪽으로 회전**시켜 목표 결합각에 맞춥니다.
스캔 + 미세 보정으로 각도를 맞추므로 0.5° 이내로 들어갑니다.

## 판정 기준

원자 종류별 개수 + 결합 인접 관계 + 중심 원자만 비교합니다. 결합 차수는 화면에 표시만 하고 판정에는 넣지 않았습니다.
판정 기준이 복잡할수록 "틀렸는데 이유를 모르는" 경우가 생기므로, 확실히 맞는 것만 넣습니다.

## 설계 메모

- 배치 계산 결과에 **분자 평면을 정면(Z축)으로 돌리는 보정**을 넣었습니다. 결합각이 맞아도 분자가 옆으로 누워 있으면 도형을 읽을 수 없습니다.
- 원소 라벨은 **원자 중심에서 분자 중심 반대 방향**으로 밀어 둡니다. 그래야 다른 원자에 가려지지 않습니다.
- 결합은 **실린더를 두 원자 사이에 늘려서** 매 프레임 갱신합니다. 지오메트리를 매번 새로 만들지 않습니다.
- **각도는 라디안과 도를 섞지 않습니다.** 수학 함수는 `targetBondAngleRad`처럼 라디안만 반환하고, 화면에 쓰는 값은 `targetBondAngleDeg`처럼 `Deg`가 붙습니다. `TARGETS[].angleDeg`도 같은 규칙입니다.

## 판정의 다중집합 비교

`validate`는 이웃 원자를 **다중집합**으로 비교합니다. "목표에 H가 2개"라면 실제 이웃도 H가 2개여야 합니다.
단순히 "목표 원소가 전부 포함되는가"만 보면 H1개+O1개도 H2개로 통과합니다. 유닛 테스트가 이 경우를 잡아냅니다.

## 검증

```bash
node ../scripts/shot.mjs molecule        # 4시점 캡처 + 자동 판정
npx vitest run minimax-m31-test/molecule # 유닛 테스트 16개
```

`src/invariants.js`가 매 0.5초마다 검사하고, 위반이 있으면 화면 하단에 배지가 뜹니다.
검사 항목: 실측 결합각이 목표와 1° 이내인가 / 분자 평면(또는 대칭축)이 시선을 향하는가 / 원자가 서로 겹치지 않는가 / 결합이 없는가.
가독성 검사는 **기본 시점에서만** 동작합니다. 다른 시점은 진단용이라 각도가 다르게 보이는 게 정상입니다.
