# 3D 타워 디펜스

길 위에 타워를 세워 5개 웨이브의 적을 막는 3D 아케이드 게임입니다.
경로 추적, 타워 조준, 발사체 비행, 웨이브 진행까지 상태 머신이 붙은 완성형 게임입니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/
```

## 조작

- **타워 버튼** (고속 60 · 강력 100 · 범위 130 골드) — 고른 뒤 보드의 빈 셀을 누르면 설치됩니다. 길 위에는 설치할 수 없습니다.
- **다음 웨이브** — 다음 웨이브를 시작합니다. 전투 중에는 비활성화됩니다.
- **배속 1× / 2×** — 진행 속도를 바꿉니다.
- **타워 클릭** — 해당 타워를 선택하면 정보 패널이 뜹니다. **판매**를 누르면 설치 비용의 60%를 돌려받습니다.
- **다시 시작** — 초기 상태로 돌아갑니다.

## 규칙

- 시작 골드 250, 생명 20. 적을 처치하면 골드가, 적이 끝까지 도달하면 생명이 줄어듭니다.
- 타워는 **사거리 안에서 가장 멀리 진행한 적**을 겨눕니다. 목표 선택 규칙이 하나로 고정돼 있어 버가 생길 여지가 없습니다.
- 범위형 타워는 명중 지점 주변 1.35칸의 적들에게 피해를 줍니다(중심에서 멀수록 약해짐).
- 5개 웨이브를 모두 막으면 승리, 생명이 0이 되면 패배입니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/stage.js` | 렌더러·조명·고정 스텝 루프·포인터 피킹 |
| `src/grid.js` | 격자 좌표, 경로 웨이포인트, 보드·도로·지형 생성 |
| `src/towers.js` | 타워 종류 정의, 조립, 조준·사거리 판정 |
| `src/enemies.js` | 적 종류 정의, 경로 이동, 체력바 |
| `src/waves.js` | 웨이브 구성과 스폰 큐 (테스트 가능한 순수 로직) |
| `src/invariants.js` | 기하 불변식 (타워가 길 위인가, 적 겹침, 좌표 유한성) |
| `src/game.test.js` | 유닛 테스트 17개 (경로·이동·조준·웨이브) |
| `src/main.js` | 웨이브 관리, 발사체, 골드·생명, UI 배선, 불변식 배선, 상태 조회 API |

## 설계 메모

- **물리엔진을 쓰지 않았습니다.** 이동은 경로 위 선형 보간, 사거리는 2D 거리, 명중은 도착 거리 비교로 처리합니다.
- 적은 `progress`(지금까지 이동한 거리) 값을 들고 있고, 타워는 이 값이 가장 큰 적을 고릅니다. "어디가 더 가까운가" 대신 "누가 더 앞에 있는가"를 기준으로 삼아 규칙이 한 줄로 설명됩니다.
- 적의 체력바는 **카메라를 향한 평면 두 장**입니다. 캔버스 텍스처를 매번 다시 그리는 대신 스케일만 바꿉니다.
- 타워 클릭 범위는 **보이지 않는 원통 프록시**로 넓혔습니다. 본체를 그대로 쓰면 좁은 탑을 클릭하기 어렵습니다.
- 웨이브 스폰은 **시간이 적힌 큐**로 미리 만들어 둡니다. 스폰 타이머 상태를 따로 들고 있지 않아, 웨이브가 끝났는지 판단하는 조건이 "큐가 비었나" 한 가지로 끝납니다.
- 웨이브 정의와 스폰 큐는 `src/waves.js`로 분리해 **브라우저 없이 유닛 테스트**할 수 있게 했습니다. 순수 로직이 테스트 밖에 있으면 회귀를 못 잡습니다.
- 경로 지점은 웨이포인트마다 중복 없이 이어집니다. 중복이 있으면 적은 한 칸씩 제자리에서 방향을 틀게 되고 경로 길이 계산이 어긋납니다.

## 검증

```bash
node ../scripts/shot.mjs defense         # 4시점 캡처 + 자동 판정
npx vitest run minimax-m31-test/defense  # 유닛 테스트 17개
```

`src/invariants.js`가 매 0.5초마다 검사하고, 위반이 있으면 화면 하단에 배지가 뜹니다.
검사 항목: 좌표가 유한한가 / 타워가 길 위에 있는가 / 타워가 길에 너무 가까운가 / 두 적이 같은 칸에 있는가 / 적의 경로 진행도가 음수가 아닌가.
