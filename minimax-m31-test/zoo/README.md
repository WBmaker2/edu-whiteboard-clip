# 폴리곤 동물원

기본 도형(구·원기둥·원뿔)만으로 짐승을 절차적으로 조립한 3D 쇼케이스입니다.
판정이나 승패는 없고, "모델이 3D 물체를 얼마나 자연스럽게 만들 수 있는가"를 보는 자리입니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/
```

## 조작

- **종 버튼** (고양이·강아지·판다·토끼) — 해당 종 동물을 추가하고 카메라 시점을 맞춥니다.
- **동물 추가** — 현재 종의 동물을 한 마리 더 놓습니다.
- **모두 걷기** — 모든 동물이 정원 둘레를 걸어 다닙니다.
- **무대 비우기** — 동물을 지우고 현재 종 한 마리로 다시 시작합니다.
- **동물 클릭** — 그 동물이 뛰어오르며 한 바퀴 돕니다.
- **드래그 / 휠** — 시점 회전 / 확대.

## 구조

| 파일 | 역할 |
|---|---|
| `src/stage.js` | 렌더러·조명·OrbitControls·고정 스텝 루프·포인터 피킹 |
| `src/species.js` | 종 파라미터 표(몸체 비율, 귀 형태, 꼬리, 색상) |
| `src/attach.js` | 표면 부착 계산 (눈·코·귀·표식의 위치를몸체 표면 기준으로) |
| `src/animals.js` | 파라미터 → 지오메트리 조립, 애니메이션 |
| `src/world.js` | 정원 지형·나무·바위·덤불·꽃 |
| `src/invariants.js` | 기하 불변식 (좌표 유한성, 개체 겹침, 표식 파묻힘) |
| `src/animals.test.js` | 유닛 테스트 12개 (조립·표면 부착·정지 상태 위치) |
| `src/main.js` | 개체 관리, UI 배선, 불변식 배선, 상태 조회 API |

## 설계 메모

- **파라미터 표를 먼저 두고 지오메트리는 그 표를 해석합니다.** 종을 늘릴 때 코드 수정이 아니라 표 한 줄 추가로 끝납니다.
- 다리는 **힙 피벗 그룹** 안에 넣었습니다. 회전 중심이 발목이 아니라 어깨가 되어야 보행 애니메이션이 자연스럽습니다.
- 꼬리는 **중첩된 5개 세그먼트**입니다. 각 세그먼트가 자식의 부모가 되어 회전이 누적됩니다.
- 정지한 동물은 **카메라 쪽을 바라봅니다**(부드러운 회전). 걸을 때는 진행 방향(궤도 접선)을 봅니다.
- 개체 배치는 **황금각 나선**으로 흩 scatter 해 서로 겹치지 않게 합니다.
- 이름표는 `CanvasTexture` 스프라이트입니다. HTML 오버레이를 쓰면 3D와 어긋나기 때문입니다.
- 눈·코·귀·표식은 **절대 오프셋이 아니라몸체 표면 기준으로** 붙입니다(`src/attach.js`). 표식은 "최외곽 = 반지름 + 돌출"이 되도록 중심 거리를 계산하고, 눈·코는 표면에서 3분의 1만 파묻히게 앉힙니다. 이 계산이 없으면 판다의 눈이 머리 안쪽에 숨어 "하얀 덩어리"가 됩니다.
- **위치는 분기 밖에서 항상 갱신합니다.** `if (moving) angle += …` 만 조건부이고, `position` 계산은 항상 실행합니다.

## 검증

```bash
node ../scripts/shot.mjs zoo          # 4시점 캡처 + 자동 판정
npx vitest run minimax-m31-test/zoo   # 유닛 테스트 12개
```

`src/invariants.js`가 매 0.5초마다 검사하고, 위반이 있으면 화면 하단에 배지가 뜹니다.
검사 항목: 좌표가 유한한가 / 두 동물이 겹쳐 있는가 / 표식이 몸체에 파묻혔는가 / 모든 개체가 한 지점에 모여 있는가.
