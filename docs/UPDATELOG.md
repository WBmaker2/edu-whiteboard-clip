# 업데이트 내역

## 2026-10-19

### 주제마다 다른 영상 — 장면 모양을 AI가 고르고 새 레이아웃 5종 추가

- 이제 주제가 달라지면 영상의 **장면 구성과 그림 배치도 함께 달라집니다.** 예전에는 어떤 주제든 장면 순서와 카드 모양이 거의 같았지만, 이제는 스토리보드를 만들 때 AI가 **장면마다 어울리는 배치(레이아웃)를 직접 고릅니다.** 예를 들어 시간 순서가 있는 내용은 연표로, 반복되는 과정은 순환도로, 분류·단계는 계층도로, 수치·비율은 막대 차트로, 두 개념의 겹침은 벤다이어그램으로 그려집니다.
- **새 레이아웃 5종**을 추가했습니다: 타임라인(연표), 순환 다이어그램, 계층 구조도, 데이터 차트, 벤다이어그램. 기존 플로우·마인드맵·비교·인포그래픽과 합쳐 모두 9종이며, 설정 화면에서 직접 고를 수도 있습니다.
- 장면 수와 비트 수도 주제에 맞게 **3~7개 장면, 장면당 2~5개 비트**로 유연해졌습니다. 내용이 짧은 주제는 짧게, 깊은 주제는 더 자세하게 구성됩니다.
- 설정 화면의 테마·그래픽 표현에 **“주제 자동 추천”** 항목을 넣었습니다. 처음 상태는 자동 추천이며, 입력한 주제와 교과(수학·과학 → 블루프린트 도면, 역사·국문 → 웜 에디토리얼, SW·AI → 미드나잇, 생물·지구과학 → 페이퍼 일러스트 등)에 맞춰 자동으로 골라 줍니다. 원하는 값을 직접 선택할 수도 있습니다.
- 이미 만들어 둔 프로젝트는 **보이던 모습 그대로** 유지됩니다. 새로 만드는 영상에만 적용됩니다.
- 레이아웃을 직접 고르면 AI가 고른 배치보다 우선 적용되어, 마음대로 바꿀 수 있습니다.

### 3D 게임 실험 폴더 — 폴리곤 동물원·분자 빌더·타워 디펜스

- `minimax-m31-test/` 폴더에 three.js로 만든 **3D 게임 3종**을 추가했습니다. 세 게임은 서로 완전히 분리되어 있고, 빌드 단계 없이 브라우저에서 바로 열립니다.
- **폴리곤 동물원** — 기본 도형만으로 고양이·강아지·판다·토끼를 만들고 호흡·걷기·점프를 넣었습니다. 동물을 누르면 뛰어오르고, 종을 바꿔 가며 볼 수 있습니다.
- **3D 분자 빌더** — 원자를 놓고 결합으로 이어 붙여 물·메테인·암모니아·이산화탄소를 만듭니다. `자동 배치`를 누르면 VSEPR 규칙으로 결합각(물 104.5°, 암모니아 107°)까지 맞춰 모양을 잡아주고, `검사`를 누르면 정답 여부와 이유를 알려 줍니다.
- **3D 타워 디펜스** — 길에 고속·강력·범위 타워 3종을 세워 5개 웨이브의 적을 막습니다. 골드, 사거리, 파급 피해, 웨이브 진행이 모두 동작합니다.
- 설계 문서와 실행 결과 화면은 `minimax-m31-test/docs/`에 모아 두었습니다.

### 3D 게임 검증 강화 — 숫자 검사 + 기하 불변식 + 화면 검사

- 앞선 3D 게임을 만들면서 **눈으로 봐야만 찾을 수 있었던 문제 4건**을 점검하는 장비를 붙였습니다. 이제 같은 실수를 사람이 다시 찾지 않아도 됩니다.
- **숫자 검사(단위 테스트 45개)** — 분자 결합각이 104.5°로 맞는지, 동물이 겹치지 않는지, 적이 길을 따라 잘 움직이는지를 브라우저 없이 검사합니다. 숫자로 결과를 확인하므로 화면 캡처가 필요 없습니다.
- **기하 불변식(게임마다 1개씩)** — 매 0.5초마다 좌표가 정상인지, 물체가 겹치지 않는지, 길 위에 타워가 올라가지 않았는지, 분자 모양이 화면에 잘 보이는지를 검사합니다. 문제가 있으면 화면 하단에 바로 알려줍니다.
- **화면 검사(4개 시점)** — 기본·정면·측면·위에서 각각 화면을 찍어 한 각도에서만 보이는 요소를 찾고, 아무 것도 보이지 않거나 화면이 비어 버린 경우를 자동으로 잡아냅니다.
- **3D 전용 작성 규칙 5가지**를 문서로 남겼습니다. 각도는 도와 라디안으로 섞지 않기, 위치 계산은 항상 실행하기, 붙는 부품은 몸체 표면 기준으로 붙이기, 좌표 변환은 한 곳에서만, 설정값은 한 파일에 모으기입니다.
- **3D를 모델에게 맡길 때 쓰는 지침 6가지**도 함께 남겼습니다. 모양을 수치로 말하기, 부품이 표면에서 얼마나 나와야 하는지 말하기, 단위 말하기, 기준값 함께 주기, 화면 캡처로 되돌려보기, 순수 계산은 브라우저 밖에서 먼저 확인하기입니다.
- 이 점검 장치를 만들면서 **실제 버그 2건을 추가로 찾아 고쳤습니다.** 분자 판정이 이웃 원자 수를 잘못 세어 엉뚱한 분자를 정답으로 받아들이던 문제, 그리고 적이 이동하는 길의 지점이 겹쳐 들어 있던 문제입니다.

### 3D 게임 랜딩 페이지 — 카드에서 바로 플레이

- `minimax-m31-test/index.html`을 폴더의 진입점으로 만들었습니다. 3개 게임을 카드로 소개하고, 카드의 **플레이** 버튼을 누르면 같은 자리에서 바로 플레이됩니다.
- 카드의 **실제 검사 결과**를 그대로 적었습니다. 단위 테스트 개수, 콘솔 오류, 기하 불변식 위반, 시점별 화면 차이 수치가 카드의 확인란에 들어갑니다. 홍보 문구 대신 측정값이라 신뢰도가 다릅니다.
- **홍보 페이지가 거짓말하지 못하도록** 만들었습니다. 카드에 적힌 수치를 `docs/checks.json`과 대조해서, 실제 실행 결과와 하나라도 다르면 랜딩 검사가 실패합니다. 검사 수치가 바뀌면 랜딩도 같이 고쳐야 합니다.
- 카드에 마우스를 올리면(또는 키보드로 focus) 그 게임의 다른 각도 화면이 차례로 보입니다. 화면 줄이동 설정에서는 자동으로 멈춥니다.
- 각 게임 화면 상단에 **목록으로** 돌아가는 링크를 넣었습니다. 랜딩이 실제 출발점이 됩니다.
- 랜딩을 화면 크기에 맞춰 좁히면 카드가 한 줄로 내려오고, 상단 메뉴가 간결해집니다.

### 장면 전환 잡음 제거

- 장면이 바뀔 때 들리던 ‘치지직’ 잡음을 줄였습니다. 장면 음성이 끝나고 다음 장면 음성이 시작되는 지점에서 소리가 갑자기 튀지 않도록, 음성 앞뒤에 아주 짧은 페이드(약 0.02초/0.04초)를 넣었습니다. 미리보기와 내보낸 영상, MP4 모두에 적용됩니다.
- 일시정지·구간 이동으로 재생을 멈출 때도 소리가 ‘툭’ 끊기지 않고 부드럽게 줄어들도록 했습니다.
- 음성 앞부분에 붙어 있던 잡음(짧은 지직거림)을 더 잘 걸러내도록 앞머리 정리 기준을 바꿨습니다. 말이 이어지는 지점을 찾아 그 앞을 잘라내고, 첫 소리가 잘리지 않도록 짧은 여유를 남깁니다.
- 저장되는 음성 파일 자체에도 앞뒤 페이드를 적용해, 내려받은 파일과 MP4 내보내기에서도 같은 잡음이 나지 않습니다.
- 이미 만든 프로젝트는 장면의 “음성 다시 만들기”를 눌러 다시 생성하면 새 처리가 반영됩니다. (장면 경계의 ‘툭’ 소리는 음성을 다시 만들지 않아도 바로 줄어듭니다.)

### 판서랩 V3 4단계 — AI 이미지 생성과 다국어 마무리

- 장면 비트에 **AI 이미지**를 넣을 수 있습니다. 만들고 싶은 그림을 설명으로 적으면 Gemini가 그림을 만들어 판서 애니메이션과 함께 나타납니다. Imagen 모델을 먼저 시도하고, 무료 티어에서 막히면 Gemini 이미지 모델로 자동으로 넘어갑니다.
- 무료 Gemini 키를 배려해 이미지 생성도 기존 요청 대기열을 거쳐 호출 간격과 동시 실행 수를 지킵니다. 생성한 이미지는 프로젝트에 저장되어 다시 호출하지 않습니다.
- 나머지 창까지 한국어/영어 전환을 마쳤습니다: AI 퀴즈, 학생용 퀴즈 뷰어, A4 학습지, 장면 다시 쓰기, 발표 모드, 읽기 전용 공유 뷰어, 사용 안내, 저장 기록, 썸네일/카드뉴스, 비디오 내보내기, 수식 편집기, 알림, 오류 안내 화면.
- 예상 호출 수 안내(스토리보드/음성/재작성/번역/퀴즈)도 선택한 표시 언어에 맞춰 표시됩니다.
- 오류 안내 화면(예기치 않은 문제 발생 시)을 별도 컴포넌트로 분리해 화면 관리가 쉬워졌습니다.
