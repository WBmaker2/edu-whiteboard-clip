# 업데이트 내역

## 2026-10-17

### 판서랩 V2 개선

- 영상 내보내기를 더 믿고 쓸 수 있게 다듬었습니다. WebM 파일에 재생 시간 정보를 넣어 일부 플레이어에서 길이가 표시되지 않던 문제를 해결했습니다.
- MP4(H.264/AAC) 내보내기를 추가했습니다. 지원되는 브라우저에서는 실시간보다 빠르게 인코딩되고, 지원되지 않으면 WebM으로 자동 전환됩니다.
- 작업 내용이 1.5초마다 자동 저장됩니다. 브라우저를 새로 열면 “이어서 작업” 배너로 복원할 수 있습니다.
- 중요한 시점을 저장 기록으로 남기고 복원할 수 있습니다. AI 재작성 전에는 오디오가 포함된 스냅샷이 자동으로 만들어집니다.
- 실행 취소·다시 실행을 50단계까지 지원합니다. 단축키는 Ctrl/Cmd+Z, Shift+Ctrl/Cmd+Z입니다.
- 장면을 2~10개까지 추가·복제·삭제·순서 변경할 수 있고, 장면 유형(도입/전개/정리)을 바꿀 수 있습니다.
- 각 장면의 비트를 2~5개까지 추가·삭제·이동할 수 있습니다. 연출 레이아웃과 발표 모드도 비트 수에 맞춰 자동으로 배치됩니다.
- 장면 하나만 AI로 다시 쓸 수 있습니다. “더 쉽게”, “더 짧게”, “사례 중심” 등의 지시를 고르고, 적용 전에 현재안과 제안을 나란히 비교할 수 있습니다.
- 대본을 바꾸면 기존 음성에 “업데이트 필요” 표시가 나타납니다. 무료 한도를 아끼기 위해 음성을 자동으로 다시 만들지는 않습니다.
- 무료 Gemini 한도를 배려해 요청 간격을 1.2초로 두고, 생성 전에 예상 호출 수를 보여 줍니다. “나레이션 음성도 함께 생성”을 끄면 스토리보드만 1회 호출로 만들 수 있습니다.

### V2 확인한 것

- 단위 테스트 44개, 브라우저 테스트(기본 17개·AI 5개·V2 26개·MP4 4개)가 모두 통과했습니다.
- WebM 파일의 재생 시간이 실제 길이와 일치하는 것을 확인했습니다.
- Chrome for Testing에서 MP4가 1920×1080 H.264 + AAC로 정상 생성되는 것을 확인했습니다.
- 장면 편집, 자동 저장·복원, Undo/Redo, AI 재작성 diff·적용·음성 업데이트 표시를 브라우저에서 확인했습니다.
- 휴대폰 화면에서 가로 스크롤이 생기지 않는 것을 확인했습니다.

### 판서랩 첫 버전을 만들었습니다

- 브라우저 제목을 **교육용 화이트보드 영상 만들기**로 설정했습니다.
- 수업 주제를 입력하면 AI가 5단계 스토리보드와 한국어 나레이션을 만들어 주는 스튜디오를 추가했습니다.
- API 키가 없어도 **예시 프로젝트(광합성 5씬)** 로 재생, 테마 전환, 자료 만들기까지 체험할 수 있습니다.
- 화이트보드 캔버스에 4가지 색상 테마와 5가지 연출(플로우·마인드맵·비교·인포그래픽·스마트 적응형)을 넣었습니다.
- 영상 모니터에서 재생·일시정지·구간 이동·배속·자막 켜기를 사용할 수 있습니다.
- 스토리보드 큐시트에서 대본과 판서 키워드를 고치고, 씬별 AI 음성을 다시 만들거나 내 목소리로 녹음할 수 있습니다.
- 작업 초안을 브라우저에 저장하고 JSON 파일로 내보내거나 다시 불러올 수 있습니다.
- PNG 장면 이미지, SRT 자막, WebM 영상(1080p/720p)을 내려받을 수 있습니다.
- 교사용 발표 모드에 판서 단계 공개, 레이저·펜·형광펜·지우개, 강의 가이드, 단축키를 넣었습니다.
- A4 학습지(요약·빈칸·4지선다·서술형), 채점 가능한 AI 웹 퀴즈, 유튜브 썸네일과 카드뉴스 5장을 만들 수 있습니다.
- 배경 음악 3종과 볼륨 조절, 자막 언어 선택(선택적 AI 번역)을 추가했습니다.
- 휴대폰과 태블릿에서도 설정/모니터 화면을 오가며 사용할 수 있도록 반응형 화면을 적용했습니다.

### 확인한 것

- 코드 검사, 타입 검사, 프로덕션 빌드가 모두 통과했습니다.
- 자동 테스트 26개와 브라우저 테스트 17개가 통과했습니다.
- 실제 Gemini 키 대신 테스트용 응답으로 스토리보드·음성 생성·영상 내보내기 과정을 확인했습니다.
- 내보낸 영상이 1920×1080 VP9 영상과 Opus 오디오로 정상 생성되는 것을 확인했습니다.

### 알아두세요

- 영상 내보내기는 실제 재생 시간만큼 걸리며, 내보내는 동안 탭을 닫거나 다른 탭으로 오래 전환하면 느려질 수 있습니다.
- WebM 영상은 일부 플레이어에서 길이 정보가 보이지 않을 수 있지만 Chrome, YouTube, VLC에서는 재생됩니다.
- 내 목소리 녹음은 마이크 권한이 필요합니다.
- 초안은 브라우저 저장 공간에 보관되므로 브라우저 데이터를 지우면 함께 사라집니다.
