# 판서랩 V4 발전 계획 — 수업 보관함과 완성도

> 진행 상태: **완료** (2026-10-24, 0.6.0)
> 대상: `edu-whiteboard-clip` (판서랩) · 선행 문서: `docs/PLAN-V3.md`
> 정책(확정): **로그인 없이, 서버 없이** — 100% 브라우저 앱을 유지한다.
> 실행 순서: E(수업 보관함) → F(완성도) → G(편집·성능)
> 버전: `0.6.0` (완료)

## 1. 배경

V3에서 안정성·구조·제품 확장·장기 과제를 모두 마쳤다. 이제 남은 문제는 새 기능의 부족이 아니라 **수업을 계속 쌓아 두는 구조와 완성도**다.

- 저장이 `draft:latest` 한 개뿐이라 새 수업을 만들면 이전 수업이 덮어써진다. 저장 기록(스냅샷)은 10개로 제한되고, 수업 단위로 browse할 수 없다.
- 영어 UI를 주요 화면에 적용했지만 `App.tsx`의 토스트·오류 문구, 프리셋 이름·설명, 교육과정 라벨, 라이브러리 오류 메시지에 한국어가 남아 있다.
- README와 실제 동작이 어긋난다: 템플릿 6종(실제 12), 테스트 83개(실제 97), “5가지 연출”(실제 10), “5단계”(실제 3~7장면).
- CI는 smoke·V2·AI·접근성만 실행한다. 수업자료·공유·퀴즈·레이아웃·PWA 검사는 PR에서 빠져 있다.
- 초기 JS가 약 505KB raw·155KB gzip으로, V3 C3의 300KB raw 목표에 도달하지 못했다.
- PWA가 `autoUpdate`라 내보내기나 발표 중에 새 버전이 자동 적용될 수 있다.
- 접근성 자동 검사는 설정·모니터·도움말·저장 기록 4개 화면만 확인한다.

## 4. Phase E — 수업 보관함

### E1. 다중 프로젝트 보관함
- 저장 구조를 단일 초안에서 프로젝트별 키로 변경한다.
  - `project:<id>` — 프로젝트 본문(오디오·이미지 Blob 포함)
  - `project:<id>:meta` — 목록용 요약(id, title, topic, updatedAt, sceneCount, duration, aspect, themeId, hasAudio, bytes)
  - `project:<id>:history` — 해당 수업의 저장 기록(스냅샷)
  - `app:lastProject` — 마지막으로 연 수업 ID
  - 중앙 인덱스 배열을 두지 않는다. `keys()`로 프로젝트 meta를 모아 목록을 만들므로 다중 탭에서 목록이 깨지지 않는다.
- `Project`에 선택 필드 `id`, `title`을 추가한다. `version`은 2를 유지한다.
- 기존 데이터 마이그레이션
  - `draft:latest`가 있고 보관함이 비어 있으면 첫 프로젝트로 이전한다.
  - `draft:history`의 스냅샷을 `project:<id>:history`로 옮긴다.
  - `library:migrated:v1` 마커를 남기고, 검증 전까지 원본 키를 보존한다.
- UI
  - 신규 `LibraryModal`(지연 로드): 검색, 최근순 정렬, 현재 수업 표시, 열기, 복제, 이름 변경, 삭제, JSON 내보내기, 새 수업(`btn-pulse`)
  - 헤더 프로젝트 메뉴: `새 수업 / 내 수업 / JSON 가져오기`
  - 시작 배너: “최근 수업 이어서” (마지막 프로젝트)
  - 새 수업 시작 시 현재 수업은 이미 자동 저장되어 있으므로 덮어쓰기 경고를 제거한다. 내보내기·발표 중에는 새 수업을 막는다.
- 안전장치
  - 프로젝트를 전환하면 이전 프로젝트의 Blob URL을 해제하고 Undo 스택을 비운다.
  - 저장은 프로젝트 본문 → meta 순서로 쓰고, meta 실패 시 고아 본문을 정리한다.
  - 같은 수업을 두 탭에서 편집하면 마지막 저장이 이긴다. `BroadcastChannel`로 “다른 탭에서 수정됨” 안내를 띄운다(가능한 경우).
- 테스트: `tests/storage.test.ts`(fake-indexeddb) — 마이그레이션, 목록/열기/복제/삭제/이름 변경, meta 갱신, 실패 복구
- QA: `qa:library` — 2개 수업 생성 → 전환 → 새로고침 유지 → 복제/이름 변경/삭제 → 마지막 수업 복원

### E2. 저장 공간·백업 안전망
- 저장 실패(`QuotaExceededError`)를 감지해 자동 저장 상태를 `error`로 두고, “보관함에서 정리” 동작이 있는 토스트를 띄운다.
- 보관함에 전체 사용량/할당량, 프로젝트별 대략 용량, 80% 경고를 표시한다.
- 전체 백업/복원
  - `src/lib/backup.ts`: `.panseolab-backup.json`(format `panseolab-backup`, version 1)
  - 오디오·이미지 포함 여부 선택(기본 포함, 50MB 초과 예상 시 제외 안내)
  - 복원은 기존 수업을 덮어쓰지 않고 새 ID로 추가하며, 형식 검증 실패 시 아무것도 쓰지 않는다.
  - 대상: 모든 프로젝트 + 해당 저장 기록
- 도움말에 “브라우저 데이터를 지우면 수업이 사라짐” 안내를 보강한다.
- 테스트: quota 오류 모킹, 백업 왕복(미디어 포함/제외), 복원 충돌 시 새 ID
- QA: `qa:library`에 백업 → 삭제 → 복원 시나리오 추가

### E3. PWA 업데이트 안전
- `vite-plugin-pwa` `registerType`을 `prompt`로 변경하고 `virtual:pwa-register`를 사용한다.
- “새 버전이 준비되었습니다 — 지금 새로고침 / 나중에” 비차단 배너를 추가한다.
- 내보내기·MP4 변환·발표 중에는 새로고침을 보류하고, 끝난 뒤 안내한다.
- 오프라인 준비 완료 안내는 기존 오프라인 배지와 중복되지 않게 한 번만 표시한다.
- QA: `qa:pwa`에 업데이트 배너 영역 존재·자동 새로고침 없음 확인 추가(서비스 워커 갱신 시뮬레이션은 수동 확인)

## 5. Phase F — 완성도

### F1. 다국어 100% (ko/en)
- `App.tsx`의 하드코딩 한국어(약 41곳)를 `t()`로 이동한다.
- 사용자에게 보이는 라이브러리 오류를 키로 통일한다.
  - `parseProjectJson`, `gemini`, `rewrite`, `share`, `templates`, `export/*`의 오류를 `error.*` 키로 바꾸고 UI에서 `t()`로 표시한다.
- 프리셋 라벨을 현지화한다: 테마 4, 연출 10, 표현 3, 모델, 보이스, BGM, 해상도, 내보내기 형식.
- 교육과정 라벨(학교급·교과)을 현지화한다. 내부 저장 값은 기존 한국어 값을 유지한다.
- `window.confirm`/`window.prompt`를 접근성 있는 공용 다이얼로그로 교체한다.
  - `ConfirmDialog`: 씬 삭제, 수업 삭제, 새 수업 등
  - `CopyLinkDialog`: 클립보드 실패 시 링크 복사
- 생성 콘텐츠(스토리보드·자막·학습지·퀴즈)는 기존처럼 주제 언어를 유지한다.
- 테스트: ko/en 키 완전 일치(기존) + `qa:i18n`
  - 영어 모드에서 설정·모니터·보관함·내보내기·퀴즈·학습지·공유 화면을 열고, 원시 키(`settings.` 등)와 한국어 UI 문구가 노출되지 않는지 확인(수업 콘텐츠는 제외)

### F2. 문구·문서 정합성
- UI 문구: “5가지 연출” → 10가지, “5단계 교수설계” → “3~7장면 수업 설계”로 수정(ko/en).
- README 갱신: 템플릿 12종, 단위 테스트 97개, 장면 3~7·비트 2~5, 연출 10종, 다국어 적용 범위, V4 명령어, 보관함·백업·PWA 업데이트 동작.
- `docs/PLAN-V4.md` 링크와 계획 문서 안내 추가.
- `IMPLEMENTATION_PLAN.md`는 최초 구현 기록임을 명시하고 최신 계획 링크를 추가한다.
- DoD: README의 수치와 실제 소스가 일치하는지 수동 확인 + lint/test.

### F3. 접근성 2차
- `qa:a11y` 대상을 전체 화면으로 확장한다.
  - 설정, 모니터, 발표 모드, 학습지, 퀴즈, 퀴즈 뷰어, 수업자료, 비디오 내보내기, 다시 쓰기, 수식 편집기, 보관함, 저장 기록, 공유 뷰어, 오류 화면
  - 한국어·영어 모드 각각 핵심 화면 확인
- 키보드만으로 주요 흐름(수업 열기 → 재생 → 내보내기 → 보관함) 수행을 확인한다.
- 자동 저장·진행률 상태에 `aria-live`를 적용하고, 캔버스에 대체 설명을 보강한다.
- 발표 모드 단축키 안내와 포커스 이동을 점검한다.
- DoD: axe serious/critical 0건, 키보드 흐름 통과.

### F4. CI 전체 QA
- `qa:ci` 추가: `qa:smoke`, `qa:v2`, `qa:ai`, `qa:media`, `qa:share`, `qa:quiz`, `qa:layouts`, `qa:a11y`, `qa:pwa`

- CI가 새 검사를 모두 통과해야 병합 가능하게 한다.
- DoD: PR에서 `qa:ci` + build + `qa:bundle` 통과.

## 6. Phase G — 편집·성능

### G1. 씬 드래그 앤 드롭
- `StoryboardList` 씬 카드에 드래그 핸들을 추가하고 HTML5 drag & drop으로 순서를 바꾼다.
- 기존 위/아래 버튼과 키보드 `Alt+↑/↓`를 유지한다(모바일·접근성 대체 경로).
- `moveScene`을 그대로 사용해 Undo·자동 저장·활성 씬 보정이 동일하게 동작하게 한다.
- QA: 2번 씬을 4번으로 드래그 → 순서 유지 → 새로고침 후 유지 → Undo 복원 → 키보드 이동.

### G2. 초기 번들 예산
- 기준을 다시 측정한다(현재 dist: 약 505KB raw / 155KB gzip).
- 지연 로드 후보
  - `MonitorPanel`(+`StoryboardList`, `PlayerControls`, 재생 루프) — 설정 탭이 첫 화면이므로 모니터 진입 시 로드, 유휴 시간 프리페치
  - 영상 내보내기 모듈(`export/video`, `export/ffmpegConvert`) — 내보내기 시작 시 로드
  - 기존 지연 모달·KaTeX는 유지
- 목표: 초기 raw **430KB 이하**, gzip **140KB 이하** (1차 목표 135KB는 측정 약 136KB로 사실상 달성, CI 여유분 포함).
- 측정: raw 505KB → **약 427KB**, gzip 155KB → **약 136KB**. 영어 사전을 지연 로드하고 모니터·영상 내보내기·SVG를 분리한 결과다.
- `qa:bundle`이 초기 엔트리 청크만 검사하고, 총 precache 크기는 참고값으로 기록한다.
- 픽셀 골든·스모크·AI QA로 기능·시각 회귀가 없음을 확인한다.
